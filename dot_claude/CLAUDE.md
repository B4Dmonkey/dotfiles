## General Habits
- **Verify before calling something a bug** — note it as a question ("this might not work because X — intentional?") and verify the full execution context before declaring a bug.
- **Verify tool syntax before using it** — before using any non-obvious syntax (regex flags, config fields, CLI options), look it up or say you're unsure. This applies to regex engines, editor configs, CI schemas, anything. Do not guess. This rule has been multiple times — treat it as a hard stop.

## Coding practices
- **Follow tdd** - Propose a test and verify with the user. Write test before writing code.
- **When implementing code follow yagni** - implement the minimal ammount of code needed to complete a task
